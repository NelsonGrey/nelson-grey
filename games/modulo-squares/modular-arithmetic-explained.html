The math behind the game

What is modular arithmetic?

Modular arithmetic is arithmetic that wraps around instead of counting up forever. Once a value reaches a fixed limit, the "modulus," it resets to zero, the same way a clock resets after 12. It shows up constantly in computing and cryptography, and it is the entire mechanic behind this game.

The mod operator, in plain terms

When you see a mod n (often written a % n in code), it means: divide a by n, and keep only the remainder.

15 mod 4 = 3    // 15 ÷ 4 = 3 remainder 3
20 mod 5 = 0    // 20 ÷ 5 = 4 remainder 0 (divides evenly)
7 mod 12 = 7    // 7 is already less than 12, so it is unchanged

When the remainder is exactly 0, n divides a evenly, so a is a multiple of n. That single case is the rule this game is built around: a falling number belongs in a bucket exactly when the number mod the bucket's value equals zero.

Where it actually shows up

Clocks and calendars

A 12-hour clock is modular arithmetic you already use daily: 9 hours after 8 o'clock isn't 17 o'clock, it's 5 o'clock, because time wraps around every 12. That wraparound, 17 mod 12 = 5, is the entire concept.

Cryptography

Modern encryption, including the RSA algorithm that secures a huge share of internet traffic, is built on modular exponentiation: raising numbers to a power and reducing the result modulo a very large number. Every HTTPS connection you use leans on this.

Hash tables

Databases, caches and programming-language dictionaries commonly pick a storage slot by taking a value modulo the table size. It is one of the simplest ways to spread data evenly across a fixed number of buckets, which is coincidentally the same idea as this game.

Check digits

The last digit of an ISBN, and the Luhn algorithm behind credit card numbers, both compute a weighted sum and check it against a fixed modulus. It is how systems catch a single mistyped digit before it causes real damage.

Music theory

Pitches repeat every 12 semitones: a C is a C whether it is high or low. Musicians call this octave equivalence, but it is modular arithmetic with a modulus of 12, the same structure as a clock.

Try it yourself

Work these out before reading on. They are exactly the calculations the game asks you to make instantly, just without a timer:

  • 23 mod 5 = ?
  • 36 mod 6 = ?
  • 44 mod 9 = ?

Answers: 23 mod 5 = 3 (23 ÷ 5 is 4 remainder 3). 36 mod 6 = 0 (a clean multiple of 6, so this one scores). 44 mod 9 = 8 (9 × 4 = 36, and 44 − 36 = 8).

How the game turns this into a puzzle

Modulo Squares gives every falling number a set of live buckets, each labeled with a divisor. Land the number where the remainder is zero and it scores a clean division; land it anywhere else and you take a penalty. Play enough rounds and the calculation stops being a calculation: you start recognizing multiples of 6, 7 and 9 on sight, the way you read "9:00" on a clock without counting hour marks. That recognition is what the strategy guide is about building.
