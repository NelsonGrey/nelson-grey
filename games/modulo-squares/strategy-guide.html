Strategy guide

How to actually get good at Modulo Squares

The rule is simple: land the number in a bucket it divides evenly. Getting good is not about being fast at math, it is about never doing math at all. Every trick below replaces calculation with instant recognition.

Divisibility shortcuts that replace mental math

Every bucket value has a shortcut that tells you whether a falling number belongs there just by looking at it. These are the same rules taught in elementary number theory, but here they become muscle memory you build under a timer.

Divisible by 2

The last digit is even (0, 2, 4, 6, 8).

134 → last digit 4 is even, so 134 is divisible by 2.

Divisible by 3

The digits add up to a multiple of 3.

1+3+5=9, so 135 is divisible by 3.

Divisible by 4

The last two digits, read as their own number, divide by 4.

316 → 16 ÷ 4 = 4, so 316 is divisible by 4.

Divisible by 5

The last digit is 0 or 5.

210 ends in 0, so it is divisible by 5.

Divisible by 9

The digits add up to a multiple of 9, the same trick as 3 one level up.

2+7+0=9, so 270 is divisible by 9.

Buckets for 6, 7 and 8 have no single clean digit trick. For 6, check divisibility by 2 and by 3. For 8, check whether the last three digits divide by 8, which is the "divisible by 4" trick applied twice. 7 has no fast shortcut worth memorizing; spotting multiples of 7 by sight only comes from repetition. Every board always includes buckets 1 through 9 plus Dead, reshuffled into different lanes each level, so you cannot predict where 7 will land, only that it is somewhere on the board.

Bucket 1 is your safety net

Every number divides evenly by 1, and a bucket labeled 1 is on the board at every level, so there is never a falling number without a correct home. Landing in Dead is never actually necessary. If you do not immediately recognize a divisor, look for 1 rather than guessing or defaulting to Dead.

How level pacing changes as you climb

The nine buckets never change. What changes is the falling numbers and the clock. Each level widens the number range (roughly 6-18 at level 1, growing to 15-45+ by level 10 and beyond) and shortens the drop interval by about 4% per level, so you read larger numbers with less time to react. The fill target that completes a level stays fixed. None of this changes which divisibility tricks apply; it only raises how fast and how far you have to apply them.

Mistakes that keep players off the leaderboard

Doing full division under pressure

Long division on a falling tile costs you the tile. Divisibility rules exist so you never actually have to divide: check the last digit or the digit sum and move on. If you catch yourself computing an exact quotient, you are working harder than the level requires.

Forgetting bucket 1 is always a safe landing

Every board includes a bucket labeled 1, and every number divides evenly by 1, so there is always a correct bucket. Players who forget this sometimes freeze on an unfamiliar number and land in Dead by default. Dead only costs you; bucket 1 never does.

Locking onto one bucket instead of scanning all of them

It is tempting to fixate on the bucket nearest your lane. The fastest players scan every live bucket against the falling number the instant it spawns, before committing to a direction. By the time the tile is halfway down, the decision should already be made.

Playing the same speed at every level

Drop speed and number range both increase as you climb. A read-then-react rhythm that works through level 10 gets punished by level 20. Pre-scan the buckets earlier in the drop as levels get harder, rather than trying to react faster.

Chasing the leaderboard

Modulo Squares posts scores to Game Center, so you can compare against friends and the global board from the Game Center button in the app. A single strong session can move you up the board even if your lifetime play is modest, so a focused run beats a long grind.
