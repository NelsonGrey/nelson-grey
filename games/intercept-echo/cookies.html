Cookies

The Intercept Echo mobile game itself is a native app and does not use cookies — nothing you do in the game is sent to a server, so there's no cookie to set.

These support pages, however, are served from nelsongrey.com, which uses Google Tag Manager to load analytics tools that help us understand how visitors use the site. These tags only run if you accept the cookie prompt shown on your first visit; declining keeps them off.

You can change your choice at any time.

For cookie questions, contact support@nelsongrey.com.
